ส่งรายงาน
  1. เปิดฟอร์มจากลิงก์ที่ปักไว้ในกลุ่ม (ใต้ปุ่มส่งต้องขึ้น "ส่งตรงเข้าห้องแชตนี้ ✓")
  2. เลือกแท็บ: รายงานการปฏิบัติ / ตรวจความพร้อม / ตรวจปราการและอินทรี / ตรวจห้องขัง / ส่งรายชื่ออินทรี03 / สแกนบัตร / ทะเบียนรถ
  3. เลือกรายชื่อ ชป. ว.4 ตามหน้า ข้อความจะขึ้นในกรอบ "ข้อความที่จะส่ง"
  4. กด 📤 ส่งรายงาน ตรวจข้อความ กด ตกลง แล้วเลือกกลุ่มที่จะส่ง
เลือกรายชื่อ
  • กดหัวข้อระดับ แล้วกด ✅ เพื่อเลือก / ❌ เพื่อเอาออก
  • ระดับหมวด เลือก มูโนะ20 หรือ ชป.จู่โจม ใต้ชื่อ
  • ▲▼ เลื่อนลำดับชื่อ · ชื่อเดียวกันเลือกซ้ำไม่ได้
วันที่ และเวลา
  • เลือกหรือพิมพ์เวลา แล้วกด ✓ ใส่เวลานี้ลงรายงาน เวลาจึงจะเข้าไปในรายงาน
  • เวลาที่ใส่แล้วจะจำไว้ แม้ปิดเปิดแอป · อยากเปลี่ยนก็ใส่ใหม่แล้วกดยืนยันอีกครั้ง
  • ปุ่ม ใช้วันที่และเวลาปัจจุบัน = ใส่เวลาตอนนี้ลงรายงานทันที
  • ▫️ ใช้ซ่อน/แสดงข้อความคงที่ เช่น "เหตุการณ์ทั่วไปปกติ"
ชุดสำเร็จรูป (ส่ง 2 แตะ · ทุกหน้า)
  • กรอกฟอร์มให้ครบ → เปิดการ์ด ชุดเวรสำเร็จรูป → ＋ บันทึกเป็นชุด (แต่ละหน้ามีชุดของตัวเอง)
  • ครั้งต่อไปกด ส่ง ข้างชื่อชุด → ตรวจแล้วกด ตกลง เสร็จ
  • กดที่ชื่อชุด = ใส่ข้อมูลในฟอร์มเพื่อแก้ก่อนส่ง
สแกนบัตร / ทะเบียนรถ
  • กด 📷 ถ่ายรูป / เลือกรูป แล้วลากนิ้วบนรูปวาดกรอบให้ครอบเฉพาะเลข 13 หลัก หรือครอบป้ายทะเบียนทั้งป้าย
  • กด 🔍 อ่านในกรอบ — ครอบพอดี = อ่านเร็วและแม่นกว่าอ่านทั้งรูปมาก
  • เลขบัตรขึ้น ✓ ถูกต้อง = ครบ 13 หลักและหลักสุดท้ายตรงตามสูตร · ขึ้น ✗ ให้ตรวจกับบัตรแล้วแก้ในช่อง
  • อ่านไม่ได้: ลากกรอบใหม่ให้พอดีขึ้น กด ↻ หมุนรูป หรือพิมพ์เอง
  • ถ้าเปิด ใช้ Google ช่วยอ่าน ภาพเฉพาะในกรอบจะถูกส่งให้ Google อ่าน (แม่นกว่า ต้องมีเน็ต) · ไม่มีเน็ตจะใช้ตัวอ่านในเครื่องแทนเอง
  • ข้อมูลหน้านี้ไม่ถูกเก็บไว้ในเครื่อง · ถ่ายรูปใหม่ = อ่านใหม่แทนของเดิม
